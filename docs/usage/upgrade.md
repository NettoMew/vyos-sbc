# 升级与回退

[文档中心](../README.md) · [安装与首次启动](installation.md)

## 系统升级

每板构建除整盘镜像外还生成 `.iso`。已运行的设备可使用 VyOS 原生命令安装对应板型的新版本：

```text
add system image <ISO 文件路径或地址>
```

升级前先核对文件 SHA256、阅读版本说明并备份配置。按交互提示处理配置和 SSH 密钥迁移，保留旧版本作为回退入口。

新旧系统镜像可共存。先确认新版本的启动、接口、网络业务和配置正常，再考虑删除旧版本；回退沿用 VyOS 的镜像选择机制，不通过覆盖启动固件实现。

## 不会自动迁移的内容

- 额外安装的软件包。
- `/etc`、`/var/lib` 中独立于 VyOS 配置的自定义文件或服务。
- 手工部署的外置模块、固件和临时调试工具。

这些内容需另行备份并在新版本中重新部署。板级正式驱动应包含在该板的 ISO 中，而不是依赖旧系统的持久层残留。

## 系统镜像与启动固件分开管理

**ISO 升级不更新 SD 保留区或 SPI 中的 SPL / U-Boot。** 当版本要求固件与内核设备树配套更新时，仅安装 ISO 不能完成升级。

SD 整盘镜像包含该板配套启动固件，但重刷会覆盖目标卡。SPI 更新必须独立备份、定长写入和读回校验；不要将整盘镜像写入 SPI。

A5E 的固件、介质 UUID 和救援路径详见 [SD / NVMe 启动与恢复](../boards/a5e/boot.md)。无线修复的配套要求见 [AIC8800 驱动](../boards/a5e/wifi.md)。
